# How-Prosociality-Feedback-and-Psychoeducation-Improve-Motivation-to-Become-More-Prosocial

## Overview
This repository provides study materials, data, and code for the manuscript titled "How Prosociality Feedback and Psychoeducation Improve Motivation to Become More Prosocial".

## Repository Folder Structure
Materials
- "Qualtrics Survey Flow- Improving motivation to become more prosocial.pdf": survey questions included in the full study in PDF format.
- "Qualtrics Survey Flow- Improving motivation to become more prosocial.qsf": survey questions included in the full study in .qsf format.

Scripts
- "Prosocial_Motivation_Data_Cleaning.Rmd": the data cleaning script.
- "Prosocial Motivation Analysis.Rmd": the analysis script for the manuscript.
- "Prosocial Motivation Sensitivity Check.Rmd": the script for the sensitivity check.

Original data
- "Prosocial_Motivation_Raw_Data.csv": de-identified raw data of the relevant variables.

Cleaned data
- "Prosocial_motivation_cleaned_data.csv": cleaned data used for analysis. 

Figures
- Contains the figures presented in the manuscript.

## To use:
1. Install the latest version of R and RStudio.
2. Download this repository to your computer.
3. Run the R Markdown script "Prosocial_Motivation_Data_Cleaning.Rmd" in the Scripts folder to produce the cleaned data file "Prosocial_Motivation_Raw_Data.csv".
4. Run the other R Markdown scripts in the Scripts folder to complete the analysis from the manuscript.
